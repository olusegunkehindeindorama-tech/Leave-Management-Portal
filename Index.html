Leave Management Portal – UI entry

The full interactive UI is embedded as base64 in IndexB64P0.gs … IndexB64P8.gs and assembled by IndexHtmlLoader.gs (getIndexHtml_()).

In Apps Script, doGet should return HtmlService.createHtmlOutput(getIndexHtml_()) (or equivalent) so the full UI is served.

The complete source HTML used to build the base64 chunks lives in the project artifacts as Index.html / Index_full.html (re-generate B64 parts from that file if the UI changes).
